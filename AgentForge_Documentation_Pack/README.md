# AgentForge Documentation Pack

This folder contains the build-ready product, technical, architecture, API, AI/data, security, UI/UX, QA, DevOps, hackathon and pitch specifications for AgentForge.

## MVP
- AI-led business onboarding
- Website ingestion + RAG
- Personalized business agent
- Embeddable web chat
- One safe action integration
- Voice channel
- Admin/analytics
- Verifiable on-chain agent identity

## Build principle
AI handles understanding and orchestration; deterministic server code enforces authorization, tool schemas, confirmations, tenant isolation and auditability.
